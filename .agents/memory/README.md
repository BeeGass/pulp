# Memory notes

Durable facts about this codebase live here, one topic per file (`<topic>.md`). Link each note from [`../MEMORY.md`](../MEMORY.md).

This directory is not a session dump. Session dumps go in [`sessions/`](sessions/).

When a fact in a session or in the scratchpad is worth keeping, write it as a topic note and add it to the index. Do not leave the lasting copy only in `sessions/`.
