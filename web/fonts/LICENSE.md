- `plex-sans.woff2` (CSS family "IBM Plex Sans"): IBM Plex Sans 3.201, variable weight 100-700,
  the Google Fonts latin subset, unmodified.
- `plex-mono-400.woff2`, `plex-mono-500.woff2` (CSS family "Pulp Mono"): a subset of IBM Plex Mono 2.3
  (github.com/IBM/plex release v6.3.0) with the latin set plus Box Drawing U+2500-257F and U+2190,
  U+2192, U+21A9, U+2713. A subset is a Modified Version under the OFL, so it is renamed "Pulp Mono"
  to respect the Reserved Font Name. Rebuild with `.agents/scripts/build-mono-fonts.py`.
